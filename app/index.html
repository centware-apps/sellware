    What each platform accepts
    • Photos: a data file can’t carry pictures. Every platform that imports a file fetches the photos from a web address. The ZIP holds the file plus a photos folder; put that folder online, enter its address in Photo web folder, and the file’s photo links point to it.
    • Shopify: full product CSV. Products → Import. Arrives as drafts with your cost filled in.
    • eBay: draft-listings CSV for Seller Hub → Reports → Uploads. Needs a numeric Category ID.
    • Amazon: an offer file for items already on Amazon (needs UPC or ASIN). New products need Amazon’s own category template, which SellWare can’t pre-build; use the listing sheet to fill it.
    • Instagram Shop: Meta catalog CSV for Commerce Manager. Every item needs a product page link on your own website.
    • Whatnot: bulk-listing CSV, best effort. Compare against the template in Whatnot’s bulk upload menu.
    • Etsy, Walmart, TikTok Shop, Facebook, Craigslist, Poshmark, Mercari, Depop, Vinted: no CSV SellWare can target (or Excel templates that change per category), so you get a listing sheet in the platform’s own field order, plus a Copy button on every field.
